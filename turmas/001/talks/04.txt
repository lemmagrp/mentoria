- Metalinguaguem: teoria __ingênua__ de conjuntos.
    - "teoria de conjunto":
        - linguagem "formal":
            - alfabeto:
                - símbolos 'x, y, z, ...' (conjuntos)
                - "pertencimento": 'in'
                - delimitadores: '{', '}', '(', ')'
                - separadores: ','
                - proposições: 'p, q, ...'
                - predicados: 'P(x)', 'Q(y)', ...
            - gramática:
                - ((x in y) in z (...))
                - {x, y, z, ...}
                - {x, {y, z}, w, ...}
                - errado: {x in y, z, ....}
        - se 'x in y':
            - lê-se 'x pertence à y'
            - ou então que 'x é um elemento de y'.
      
        - Axioma 1:
            - se 'P' é um predicado, então:
                - existe o conjunto X(P) tal que:
                    - "x in X(p)" iff "P(x)" é verdadeiro.

            - em outras palavras:
                - para todo predicado 'P':
                    - { x tal que P(x) é verdadeiro } é um conjunto

        - pergunta:
            - será que existe o "conjunto de todos os conjuntos"?
                - existe "U" tal que se "x" é conjunto, então "x in U".

        - suponha que:
            - existe "U"
            - o Axioma 1
            
        - considere:
            - "P(x): x in x"
            - U(P) = { x in U tal que not x in x }
                - U(P) in U(P)? sim
                - U(P) not in U(P)? sim
            - contradição:
                - paradoxo de Russell
        
        - temos problemas com:
            - U: conjunto que contém todos os conjuntos
            - Axioma 1: para todo conjunto X e todo predicado P existe um novo conjunto X(P) cujos elementos são os elementos 'x in X' tais que P(x) é verdadeiro.
